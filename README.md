# أُنس أحمد — V18 (إصدار الأساس: بيانات القرآن + محرّك الصوت + المساعد)

> صدقة جارية على روح أنس أحمد وأحمد فايز الأحمد

موقع ثابت (HTML/CSS/JS) مع دالة Netlify اختيارية للمساعد الذكي. **اقرأ `docs/REPORT-V18.md` أولاً** لمعرفة ما أُنجز وما لم يكتمل وما لم يُختبر.

## التشغيل محلياً
```bash
cd uns-ahmad-v18
python3 -m http.server 8080      # أو أي خادم ملفات
# افتح http://localhost:8080
```
الموقع يعمل دون أي مفتاح. القرآن والصوت يحتاجان اتصالاً بالإنترنت أول مرة (ثم يُحفظ نص كل سورة فُتحت).

## فحص روابط التلاوة (مهم قبل النشر)
افتح `/audio-check.html` من متصفحك واضغط «ابدأ الفحص». يجرّب لكل قارئ أول آية وآية وسطى وآخر آية وملف سورة كاملة. أي ✗ يعني أن ذلك القارئ/الملف لا يعمل من شبكتك؛ أرسل لي النتيجة لأصحّح الرابط. لم أستطع فحص هذه الروابط من بيئة التطوير لأنها بلا إنترنت.

## النشر على Netlify
- **المساعد الذكي يحتاج Netlify Functions**، فانشر عبر **Git** (Import from Git) أو **Netlify CLI** (`npx netlify deploy --prod`). لم أتحقق من أن السحب والإفلات يدعم الدوال، فإن استعملته فالموقع سيعمل والمساعد سيعرض «غير مُفعّل».
- Publish directory = `.` وBuild command فارغ (مضبوطان في `netlify.toml`).
- بعد النشر: أعد نشر الموقع بعد رفع التعديلات. لا يلزم إضافة `ANTHROPIC_API_KEY` أو مفتاح Gemini API لهذا الاتصال.

## إعداد المساعد الديني الذكي
المساعد الشرعي يتصل الآن بواجهة الويب الداخلية غير الرسمية لـ Gemini الموجودة في السكربت المرفق. لا يلزم مفتاح API رسمي أو متغيرات سرية للمساعد. يمكن ضبط `AI_ALLOWED_ORIGIN` اختياريًا لتقييد CORS.
افتح `/.netlify/functions/chat` في المتصفح: يجب أن ترى `{"configured":true}`.
- الحماية الحالية: التحقق من المدخلات، سقف طول، 12 طلباً/دقيقة لكل عنوان (في ذاكرة الدالة، تقريبي). للحماية الأقوى فعّل Rate Limiting من Netlify أو خدمة مثل Upstash.
- لا يلزم مفتاح API رسمي؛ لكن واجهة Gemini الداخلية غير الرسمية قد تتغير أو تتطلب جلسة/تحققًا أو تمنع طلبات الاستضافة. عندها قد يتوقف المساعد حتى تحديث طريقة الاتصال.
- **المساعد نموذج لغوي وقد يخطئ.** يُنصح بمراجعة أهل العلم والمصاحف المعتمدة. قد تظهر روابط يذكرها النموذج في نص إجابته؛ لا يوجد بحث مباشر موثّق في هذا التكامل، لذا يجب مراجعة الروابط والأدلة يدويًا.

## تصحيح التلاوة المتقدم (Nabr) — اختياري
يحتاج خادماً وسيطاً بـ WebSocket ومفتاح Nabr؛ **Netlify لا يصلح لتشغيله**.
1. شغّل `server.js` على استضافة تدعم WebSocket (Render/Fly/Railway/VPS) مع المتغيرات `NABR_API_KEY` و`ALLOWED_ORIGINS=https://موقعك`.
2. ضع العنوان في `js/config.js`: `NABR_WS_URL: 'wss://خادمك/nabr'`.
3. بدون ذلك تظهر رسالة توضح أن الخدمة غير مفعّلة، ويبقى «التسجيل التقريبي» المدمج في المتصفح (مقارنة نصية تقريبية، ليست حكماً على التجويد).
- لم أختبر Nabr لأنه يتطلب مفتاحاً وشبكة.

## مصادر البيانات
- **نص الآيات (رواية حفص، الرسم العثماني):** `api.alquran.cloud` (أساسي) ثم `api.quran.com` (احتياطي). يُرفض أي رد لا يطابق عدد الآيات المعتمد (مجموع 6236) أو يحوي ثغرات، ثم تُجرَّب الجهة الأخرى. تُحفظ كل سورة صحيحة في IndexedDB.
- **الصوت:** ملفات الآيات من `everyayah.com` (احتياطي `cdn.islamic.network`)، وملفات السور من `mp3quran.net`. تُبثّ من مصادرها ولا تُضمَّن في المشروع. راجع شروط استخدام كل موقع قبل أي توزيع أو تنزيل جماعي.
- **تصنيف مكية/مدنية:** وفق بيانات Tanzil (وفي بعض السور خلاف معتبر بين العلماء).

## المساعد الشرعي — إعداد مهم
- واجهة المساعد في `js/ai.js` تتصل بالخادم `netlify/functions/chat.js`، ولا تضع مفاتيح API في المتصفح.
- تم ضبط تعليمات المساعد ليقتصر على الأسئلة الإسلامية الشرعية وفق المنهج السني السلفي، مع طلب الدليل واسم المصدر والرابط عند توفره.
- تم استبدال تكامل Anthropic باتصال خادمي إلى واجهة Gemini الداخلية كما في «جيميني دون حظر.py». الطلبات تمر عبر Netlify Function ولا تُرسل تعليمات المساعد من المتصفح مباشرة.
- **تنبيه:** هذه واجهة غير رسمية وليست Google Gemini API. لا توجد ضمانة للاستقرار أو السماح بالاستخدام على الاستضافة، ولا توجد أداة بحث موثقة مدمجة هنا؛ لذلك تعليمات ذكر المصادر تمنع اختلاقها لكنها لا تضمن تحققًا حيًا من كل رابط.
- لا تضع كلمات مرور أو رموز جلسات خاصة في المستودع. احمِ نقطة الاتصال من الاستخدام المفرط، وراقب حدود Netlify وقيود الخدمة.
- تنبيه: تعليمات النموذج تقلل الإجابات خارج الاختصاص وتُلزمه بتوثيق الأدلة، لكنها لا تضمن وحدها صحة كل فتوى؛ راجع المصادر الظاهرة في كل جواب.
